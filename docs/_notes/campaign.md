# Campaign slice: the world remembers and grows (D-035)

Goal: the loop gains a FUTURE. Powers beyond the Ward have faces, wants and a map of grudges; the Syndicate becomes a persistent agent with goals that moves while you are away; the party can plant an outpost with its hands and watch it evolve
(camp -> trading post -> fortified outpost -> settlement -> town) while roads, a telegraph and a steam launch appear as consequences, not menu items; the whole campaign survives a server restart; and the release-hygiene debt of D-033/D-034 is paid.
Verified-by-reading against: slice.md, expedition.md, BUILD_STATE (every open finding: see section 9), GDD 3-5, WorldRoom.ts (onCreate/onDispose/commitOutcome/useStation/buildRegion/rebuildBridge/landfall), factions.ts (RULES, wardMemory, parse*), newspaper.ts,
scenario.ts, scenarios/registry.ts (`pickTemplate`), kessar.ts (`kessarObstacles`, `createKessarWorld`), regions.ts, props.ts, camp.ts (`hqPlan`), Session.ts (`worldFor`, `refreshWorld`), app.ts, config.ts, Game.ts (`mountPromptNow`, `plate`), scripts/shot.mjs.
Measured while writing: a full campaign JSON is 1.8 KB (12 history entries); `onDispose` may return a Promise (Colyseus 0.18 types); `loadConfig({NODE_ENV:"test"})` already defaults `debugCommands` on; `@electric-sql/pglite` 0.5.8, `drizzle-orm` 0.45.3, `postgres` 3.4.9 are installable here (registry reachable) - verify APIs against the installed types.
Process is D-033/D-034's: a frozen contract (phase 0), four packages with DISJOINT files, one integrator. Only O runs `scripts/shot.mjs` (or a throwaway script in the scratchpad that drives UI states with the same browser launch) and it must LOOK at every render it claims.
